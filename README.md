# predictions 20241021 0000 72h
> An interactive, editorial data story powered by DataMorph AI.

This project is a standalone Next.js 14 web application grounded in verified dataset records. It features a data-first hero section, scroll-driven pinned narrative visualizations, bento analytics, an interactive data explorer, and an integrated AI chatbot.

---

## 🚀 Quickstart

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Locally**:
   ```bash
   npm run dev
   ```

3. **Open in Browser**:
   Visit [http://localhost:3000](http://localhost:3000)

---

## 🤖 AI Chatbot Configuration (Optional)
The application includes a deterministic mathematical query engine that functions out-of-the-box with zero API keys. To connect advanced LLM reasoning, copy `.env.example` to `.env.local` and add your `GEMINI_API_KEY` or `OPENAI_API_KEY`.

---

## 🚢 Deployment
Deploy to Vercel or Render in one click:
- **Build Command**: `npm run build`
- **Start Command**: `npm run start`
